## ✨ Features

### **Authentication UI**
- **Login/Signup Toggle** - Smooth tab switch with animations
- **Email & Password Fields** - Clean, accessible inputs
- **Password Visibility Toggle** - Show/hide password with icon
- **Remember Me** - Checkbox for persistent sessions
- **Forgot Password** - Link to reset flow

### **Validation**
- **Real-time Validation** - Email format, password strength
- **Error States** - Inline error messages with shake animation
- **Success States** - Green border on valid input
- **Empty Field Check** - Prevents submission with empty fields

### **UI/UX**
- **Glassmorphism Design** - Modern frosted glass effect
- **Dark/Light Mode** - Theme toggle with localStorage
- **Social Login Buttons** - Google, GitHub, Apple UI ready
- **Loading States** - Spinner on submit button
- **Responsive** - Mobile-first, works on all devices
- **Animations** - Fade-in, slide, shake effects

### **Security UI Features**
- **Password Strength Meter** - Weak/Medium/Strong indicator
- **Auto-complete Attributes** - Proper `autocomplete` for browsers
- **No Password in DOM** - Inputs cleared on toggle

## 🛠️ Tech Stack

- **HTML5** - Semantic markup, accessibility
- **CSS3** - Custom properties, Flexbox, Grid, Animations
- **JavaScript** - ES6+, Form validation, DOM manipulation
- **Zero Dependencies** - No frameworks, no libraries
